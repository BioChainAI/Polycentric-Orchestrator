# biochain-polycentric-orchestrator

Separate network-facing Polycentric Orchestrator: admission gates, explicit calibration registry, clock checks, evidence history, exact TQF scene state and central manifold Mind’s Eye snapshot. Reference transport serves only loopback.

Integration: contracts are defined by the shared `biochain-shdccp-core` releases. This repository is designed to be split and versioned independently; currently all six roots share a developer umbrella workspace.

Reference command from workspace root: `python ../../run_demo.py`
